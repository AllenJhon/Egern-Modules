# Egern-Modules
个人整理的 Egern 规则模块，用于广告拦截、域名过滤等。

## 📦 模块列表
| 名称 | 链接 | 说明 |
| ---- | ---- | ---- |
| 番茄小说去广告 | `https://cdn.jsdelivr.net/gh/AllenJhon/Egern-Modules@main/modules/fanqie-novel.yaml` | 拦截番茄小说广告域名 |

## 📖 使用说明
1. 打开 Egern
2. 进入「规则」页面，添加【远程规则】
3. 复制上面对应链接粘贴进去，保存
4. 开启代理，规则自动生效

> 💡 提示：
> - cdn 链接国内访问更稳定，但是提交更新后有缓存延迟（1~3分钟）
> - raw 链接实时生效，但国内网络可能访问失败
> - 测试广告前建议把 App 后台完全关闭重新打开，清除本地缓存广告

## 📝 更新方式
1. 进入仓库，点 `Add file` → `Create new file`
2. 文件名填写 `modules/xxx.yaml`
3. 粘贴规则代码，提交即可
4. 新增模块记得同步更新本 README 表格
